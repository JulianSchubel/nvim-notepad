# Stage 2 — Markdown Flashcard Parsing

Flashcards are identified by a markdown-based flashcard parser designed with
interoperability with Obsidian in mind.

## Supported Patterns

### Inline
```md
Question :: Answer
```

### Question Answer Pairs
```md
Q:: ...
...
A:: ...
```

### Obsidian Callouts (Recommended)
```md
> [!flashcard]
> Front
> Back
```
